# Data Analyst - Reference Notes
## Data quality and cleaning
Mulai dengan data profiling: tipe data, missing values, duplikasi, rentang nilai, konsistensi kategori, dan aturan bisnis. Jangan menghapus missing values tanpa memahami pola dan dampaknya. Pilihan dapat mencakup imputasi, penghapusan, atau mempertahankan missingness sebagai informasi, bergantung konteks.
## SQL
WHERE memfilter baris sebelum GROUP BY/agregasi; HAVING memfilter grup setelah agregasi. Primary key mengidentifikasi baris secara unik; foreign key merepresentasikan relasi dan integritas referensial.
## Exploratory data analysis
EDA memeriksa distribusi, outlier, tren, segmentasi, dan hubungan awal. Korelasi/asosiasi tidak otomatis membuktikan kausalitas.
## Statistics
Mean sensitif terhadap nilai ekstrem; median lebih robust untuk distribusi menceng. Pemilihan uji statistik mempertimbangkan desain, independensi, distribusi, ukuran sampel, dan tujuan analisis.
## Visualization and metrics
Line chart cocok untuk tren waktu; bar chart untuk perbandingan kategori. Definisi metrik, grain, periode, denominator, dan segmentasi harus konsisten.
